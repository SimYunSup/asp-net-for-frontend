# 부록 (Appendices)

프론트엔드 개발자를 위한 ASP.NET Core 가이드의 부록 자료입니다. 빠른 참조와 추가 학습 자료를 제공합니다.

## 부록 목록

### [Appendix A: C# 문법 빠른 참조](./appendix-a.md)
C# 언어의 핵심 문법을 JavaScript/TypeScript와 비교하여 설명합니다.

**주요 내용**:
- 기본 타입과 변수 선언
- 컬렉션 (배열, List, Dictionary)
- 제어문 (if-else, switch, for, foreach)
- 함수와 메서드
- 클래스와 객체
- 제네릭
- LINQ
- 비동기 프로그래밍 (async/await)
- 예외 처리
- 레코드와 구조체
- 패턴 매칭
- 델리게이트와 이벤트
- 특성 (Attributes)
- 확장 메서드
- Nullable 참조 형식

### [Appendix B: .NET CLI 명령어 참조](./appendix-b.md)
.NET CLI의 모든 주요 명령어를 실무 예제와 함께 설명합니다.

**주요 내용**:
- 기본 명령어 (버전 확인, 도움말)
- 프로젝트 생성 및 관리
- NuGet 패키지 관리
- 빌드 및 실행
- 테스트
- 도구 (Global Tools, Local Tools)
- Entity Framework Core 명령어
- 사용자 비밀 (User Secrets)
- 개발 인증서
- 코드 정리 및 포맷팅
- 성능 및 진단
- 워크로드 (Workloads)
- npm과의 비교

### [Appendix C: Entity Framework Core 마이그레이션 가이드](./appendix-c.md)
EF Core 마이그레이션의 모든 측면을 다루는 종합 가이드입니다.

**주요 내용**:
- 마이그레이션 기본 개념
- 초기 설정 (CLI 도구, 패키지, DbContext)
- 마이그레이션 생성
- 데이터베이스 업데이트
- SQL 스크립트 생성
- 마이그레이션 관리
- 복잡한 마이그레이션 (데이터 시드, 칼럼 이름 변경, 데이터 변환)
- 다중 DbContext
- 고급 시나리오 (마이그레이션 번들, 프로덕션 전략)
- 문제 해결
- 모범 사례
- Prisma/TypeORM과의 비교

### [Appendix D: 유용한 NuGet 패키지 모음](./appendix-d.md)
실무에서 자주 사용하는 NuGet 패키지를 카테고리별로 정리했습니다.

**주요 카테고리**:
- 데이터베이스 및 ORM (EF Core, Dapper)
- API 문서화 (Swagger, NSwag)
- 인증 및 권한 (JWT, Identity, OAuth)
- 데이터 검증 (FluentValidation)
- 로깅 (Serilog, NLog)
- HTTP 클라이언트 (Refit, RestSharp)
- JSON 처리 (Newtonsoft.Json)
- 매핑 (AutoMapper)
- 캐싱 (Redis, Memory Cache)
- 백그라운드 작업 (Hangfire, Quartz.NET)
- 실시간 통신 (SignalR)
- 테스트 (xUnit, Moq, FluentAssertions, Playwright)
- 모니터링 및 APM (Application Insights, OpenTelemetry, Prometheus)
- 메시징 (MassTransit, RabbitMQ)
- 문서 생성 (iTextSharp, ClosedXML)
- 이미지 처리 (ImageSharp)
- 날짜 및 시간 (NodaTime)
- Rate Limiting
- 보안
- 유틸리티 (Polly, Bogus, Humanizer)
- 성능 (BenchmarkDotNet)
- GraphQL (HotChocolate)
- gRPC
- npm 패키지와의 비교

## 사용 방법

### 빠른 참조
개발 중 특정 문법이나 명령어를 찾을 때 사용합니다:
- C# 문법을 잊었을 때 → Appendix A
- CLI 명령어를 잊었을 때 → Appendix B
- 마이그레이션 문제가 생겼을 때 → Appendix C
- 특정 기능을 구현할 패키지를 찾을 때 → Appendix D

### 개발 환경 설정
새 프로젝트를 시작하거나 팀 표준을 만들 때:
- IDE 설정 → Appendix E
- .editorconfig, StyleCop 설정 → Appendix E

### 학습 계획 수립
다음에 무엇을 학습할지 고민될 때:
- 학습 자료 탐색 → Appendix F
- 6개월 학습 로드맵 → Appendix F

### 용어 이해
생소한 용어를 만났을 때:
- 용어 검색 → Appendix G
- JavaScript 용어와 비교 → Appendix G
